## Ingestion 

1. Consume text from forms 
2. Break them into chunks of 400 to 600 chars each (with a bit of overlap so nothing important gets cut a boundary)
3. Run each chunk throungh an embedding model, which turns into a vector
4. Store each chunk and its vector in Postgres

## Query Phase

1. Embed the user's question using the **same model**
2. Search in the database for chunks whose vectors are closest to the question vector 
3. Take top 5 matching chunks and assemble them into a context block
4. Send `context + question` to the LLM and return its answer
